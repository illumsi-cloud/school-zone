
# 충주시 초·중학교 통학구역 검색 서비스

충주시 초·중학교 통학구역 및 중학구를 동·리, 통·반, 아파트명, 학교명으로 검색할 수 있는 정적 웹 애플리케이션입니다. 별도 백엔드 없이 HTML·CSS·JavaScript 단일 파일과 연도별 CSV로 동작합니다.

- 시연 페이지: https://illumsi-cloud.github.io/school-zone/
- 공식 서비스: 충주교육지원청 홈페이지 내 게시 예정
- 문서 버전: v3.0 (2026-06-11)
- 운영 주체: 충주교육지원청

## 1. 기술 스택

| 구분 | 내용 |

| 프론트엔드 | HTML5 / CSS3 / Vanilla JavaScript (ES2020+) |

## 2. 저장소 구조

```
school-zone/
├── index.html          # 단일 실행 파일 (UI · 검색 로직 · 스타일 포함)
├── 2026.csv            # 학년도별 통학구역 데이터
├── 2027.csv            # 학년도별 통학구역 데이터
├── README.md           # 본 문서
└── docs/
    ├── 기능명세서_v3.0.docx
    └── 원자료 작성 표준 서식.xlsx
```

`index.html`과 `{연도}.csv`는 동일 디렉터리에 배치되어야 합니다.

## 3. 로컬에서 미리보기

> 운영 담당자는 이 섹션을 건너뛰어도 됩니다. 코드를 수정한 뒤 GitHub 또는 충주교육지원청 홈페이지에 업로드하기 전, 개발자가 자기 PC에서 동작을 확인할 때 필요한 안내입니다.

`index.html`을 더블클릭으로 직접 여는 방식(`file://` 실행)은 Fetch API의 CORS 제약 때문에 CSV를 읽지 못해 화면이 정상 동작하지 않습니다. 간이 HTTP 서버를 띄워주세요.

### 3.1 파이썬

```bash
cd school-zone
python -m http.server 8000
```

### 3.2 Node.js

```bash
cd school-zone
npx serve .
```

서버가 켜지면 브라우저에서 `http://localhost:8000` 접속. 확인이 끝나면 `Ctrl + C`로 서버를 종료합니다.

## 4. 배포

이 서비스는 두 환경에서 운영됩니다. CSV 갱신 시 두 곳 모두에 동일한 파일을 업로드합니다.

### 4.1 시연 환경 — GitHub Pages

개발사와 청 담당자가 결과를 빠르게 공유·검증하기 위한 환경.

1. `main` 브랜치에 `index.html`, `{연도}.csv` 커밋·푸시
2. Settings → Pages → Source: `main` / `/ (root)` 선택
3. 1~2분 후 `https://{org}.github.io/school-zone/` 에서 확인

### 4.2 공식 서비스 환경 — 충주교육지원청 홈페이지


1. `index.html`과 모든 `{연도}.csv`를 같은 디렉터리에 업로드
2. 디렉터리 인덱스 또는 메뉴 링크에서 `index.html` 지정
3. 정적 파일 캐시 TTL을 1시간 이하로 설정 (CSV 교체 즉시 반영)

### 4.3 배포 후 점검

각 환경별로 다음을 확인합니다.

- 페이지 진입 시 로딩 스피너 후 학년도 탭 정상 표시
- 최신 학년도 탭 기본 활성화
- "성서동", "칠금초", "센트럴푸르지오" 등 표본 검색어로 결과 노출
- 자동완성 드롭다운 정상 동작
- CSV 미배치 시 "현재 등록된 통학구역 자료가 없습니다." 안내 노출

## 5. 데이터 갱신 절차

매년 학구 변경 고시 이후 신학년도 CSV를 추가합니다.

```
docs/원자료_작성_표준_서식.xlsx
        │
        ▼ 담당자가 신학년도 데이터 입력
        │
        ▼ "CSV UTF-8(쉼표로 분리)(*.csv)" 형식으로 저장
        │
2027.csv  ← 파일명: {학년도}.csv
        │
        ▼ 4.2 청 홈페이지에 업로드
        │
       완료 (페이지 새로고침 시 자동 인식)
```

### 5.1 엑셀에서 UTF-8 CSV로 저장

1. `파일 → 다른 이름으로 저장`
2. 파일 형식에서 `CSV UTF-8(쉼표로 분리)(*.csv)` 선택
3. 파일명은 `2027.csv` 형태 (4자리 학년도)
4. 저장 후 메모장으로 열어 한글이 깨지지 않는지 확인

> Warning  
> 파일 형식 목록에서 일반 `CSV(쉼표로 분리)`를 고르면 한글이 `???`로 깨집니다. 반드시 `CSV UTF-8(...)` 항목을 선택하세요.

### 5.2 필수 컬럼

자세한 헤더와 예시는 `docs/원자료 작성 표준 서식.xlsx`를 참고하세요. 주요 컬럼:

```
법정동(읍∙면), 법정리(통), 행정리(반), 구역(번지), 제외 구역(번지),
공동주택명, 초등학교명, 초등학교 공동학구, 초등학교 공동(일방)학구,
중학구, 중학교 공동학구, 중학교 공동(일방)학구, 추첨학교,
참고, 행정복지센터
```

복수값 구분자는 `/` 또는 `,` 입니다.

### 5.3 갱신 후 확인

업로드 직후 4.3의 점검 항목을 한 번 더 수행합니다.

## 6. 파일명 및 인코딩 규칙

| 항목 | 규칙 |
|---|---|
| 파일명 | `{4자리 학년도}.csv` (`2026.csv`, `2027.csv`) |
| 인코딩 | UTF-8 (BOM 유무 무관). EUC-KR도 자동 폴백 지원 |
| 줄바꿈 | LF / CRLF 모두 허용 |
| 헤더 | 1행 = 컬럼명, 2행부터 데이터 |
| 따옴표 처리 | 쉼표·줄바꿈 포함 셀은 `"…"`로 감싸고, 내부 따옴표는 `""`로 이스케이프 |

파일명 규칙을 벗어나면(`2026년.csv`, `2026-1.csv`, `2026 학년도.csv` 등) 자동 탐지에서 누락됩니다.

## 7. 연도 자동 탐지 로직

페이지 로드 시 `index.html`은 다음과 같이 동작합니다.

```
1. 현재 연도 기준 -10년 ~ +2년 (총 13개 연도) 범위 결정
2. 각 연도에 대해 ./{연도}.csv HEAD 요청 병렬 발송 (Promise.all)
3. 200 OK 응답한 연도만 수집
4. 수집된 연도 중 최신 2개만 GET으로 다운로드 (Promise.all)
5. 가장 최신 학년도를 기본 탭으로 활성화
```

| CSV 파일 수 | 화면 표시 |
|---:|---|
| 0개 | "현재 등록된 통학구역 자료가 없습니다." 안내 |
| 1개 | 해당 연도 탭 1개 |
| 2개 | 두 연도 탭 |
| 3개 이상 | 가장 최근 2개 학년도 탭만 표시 |

지난 학년도 CSV는 파일을 보관하더라도 화면에는 표시되지 않으므로, 별도 정리 작업 없이 매년 신규 CSV만 업로드하면 됩니다.

## 9. 트러블슈팅

| 증상 | 점검 사항 |
|---|---|
| 학년도 탭이 표시되지 않음 | CSV 파일명이 `{4자리}.csv`인지, `index.html`과 같은 폴더인지 확인 |
| 한글이 `???`로 깨짐 | CSV 저장 시 일반 `CSV`로 저장한 경우. 5.1을 따라 재저장 |
| 검색은 되는데 특정 행이 안 나옴 | 헤더명이 표준서식과 일치하는지 확인 (공백·괄호 포함 정확히) |
| 자동완성이 비어 있음 | CSV 첫 줄(헤더) 누락 또는 인코딩 오류. 메모장으로 열어 확인 |
| 캐시로 옛 데이터가 보임 | 브라우저 강제 새로고침 (`Ctrl + F5` / `Cmd + Shift + R`) |
| 청 홈페이지만 옛 데이터 | 홈페이지 캐시 TTL 확인 (4.2 참고) |

브라우저 개발자 도구(F12) 콘솔에 `{연도}.csv 로드 실패` 로그가 찍히면 해당 파일의 HTTP 응답(404 / 500 등)을 먼저 확인합니다.
